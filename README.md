# 倒數計時器與節拍器

在瀏覽器開啟就能用的小工具，不需安裝：

- **計時響鈴**：2／5／10／20／30 分鐘或自訂時間，時間到響鈴。
- **睡眠模式**：播放自己的錄音檔（可拖曳進度條、調整 0.5–2 倍播放速度），時間到自動關閉。
- **節拍器**：可設定「幾個幾拍」（例如 4 個八拍、2 個四拍），中文語音喊數，可調速度、輪數與預備拍。

## 使用方式

直接用瀏覽器開啟 `index.html`，或透過 GitHub Pages 開啟網址。錄音檔只在你的瀏覽器裡播放，不會上傳。
